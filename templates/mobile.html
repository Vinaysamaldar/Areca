Architectural Flexibility

Dual Inference Modes: Offline Edge & Online Cloud

Seamlessly switches between on-device hardware inference and central REST server depending on plantation network availability.

Mode 1: On-Device TFLite (Offline)

Default Recommended Mode
  • Model Bundle: assets/models/model.tflite and labels.txt embedded inside APK.
  • Latency: Ultra-fast response (< 250 milliseconds) directly on mobile CPU/GPU.
  • Zero Data Cost: No internet connection or mobile data packet required.
  • Local Logging: Past scans recorded locally using SQLite / Hive database.

Mode 2: Online REST API (Cloud)

Configurable in App Settings
  • Endpoint: Sends multipart POST request to POST /predict on ArecaAI server.
  • Centralized Sync: Synchronizes scan records across web and mobile dashboards.
  • Full Agronomic DB: Pulls live localized weather advisories and agricultural schemes.
  • Automatic Fallback: Automatically switches to Mode 1 (Offline) if network times out.

How to Build & Run the Android APK

Commands to test in emulator or generate a standalone release APK for farmers.

1. Navigate to Mobile App Directory & Fetch Dependencies

cd mobile_app

flutter pub get

2. Run in Debug Mode on Connected Phone / Emulator

flutter run

3. Build Standalone Release APK

flutter build apk --release

# Output: build/app/outputs/flutter-apk/app-release.apk

4. Convert Trained Keras Model to TFLite (Optional)

python mobile_app/convert_to_tflite.py

# Produces: mobile_app/assets/models/model.tflite with Float32 normalization
